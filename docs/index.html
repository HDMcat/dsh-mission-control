安装 / Install

需要 Node.js 20+，无 npm 运行时依赖。完整步骤以仓库 README 为准。

git clone https://github.com/HDMcat/dsh-mission-control.git
cd dsh-mission-control
npm start        # synthetic demo, http://127.0.0.1:7799/

在 DSH：Plugins → Add plugin → Install a third-party plugin，选择本仓库目录，Enable now。FULL 会打开独立全屏 HUD。

隐私边界 / Privacy

  • loopback only：127.0.0.1:7799 / 7800
  • 压缩面板不上传会话、命令、路径或凭据
  • 完整 HUD 的会话内容只在本机渲染
  • 进程控制默认关闭；文件监视需显式配置
  • 不能读取的传感器显示 N/A，不编数字
